# Mixtape-ios-video-editing-software

iOS video editor built with SwiftUI and **MVVM** per feature module.

## Project structure

```
App/                 # MixtapeApp entry
Core/                # Theme, shared UI, audio session
Features/
  Editor/            # Model · ViewModel · View · Services
  ProjectList/       # Model · ViewModel · View
```

See [Features/README.md](Features/README.md) for the full MVVM layout and conventions.
